# V4.7 — Hata düzeltmeleri

SQL: `sql/panel_v4_6_arama_optimizasyon.sql`

## 1. `Event handlers cannot be passed to Client Component props` ✅

Reklamlar sayfası bir **sunucu bileşeni**; içine `onChange` koymuşum. React bunu serileştiremiyor. Select ayrı bir client bileşene (`StatusFilter.tsx`) taşındı.

Bir daha olmaması için tüm sayfaları taradım:
```
✓ Sunucu bileşenlerinde olay işleyicisi yok
✓ "use server" dosyalarında senkron export yok
```

Ayrıca `upload.actions.ts` içinde senkron bir `export function` vardı — `"use server"` dosyaları **sadece async** fonksiyon export edebiliyor, bu da build'i kırıyordu. `lib/upload-name.ts`'e taşındı.

## 2. "Body exceeded 1 MB limit" ✅ — doğru çözümle

Server Action gövde sınırını büyütmek yetmezdi: 200 MB'lik videoyu Next.js sunucusundan geçirmek zaten yanlış (bellek şişer, zaman aşımı olur, serverless'ta hiç çalışmaz).

**Artık dosya sunucudan geçmiyor:**

```
1. Panel sunucudan İMZALI YÜKLEME URL'i ister   (birkaç bayt)
2. Tarayıcı dosyayı DOĞRUDAN Supabase'e gönderir (XHR, ilerleme çubuklu)
3. Panel sunucuya "şu yola şu dosya yüklendi" der (birkaç bayt)
```

Yükleme sırasında **yüzde göstergesi** var (XHR kullandım çünkü `fetch()` ilerleme bildirmiyor). Sınırlar bucket'a göre: galeri 200 MB, reklam 20 MB, media 50 MB.

Küçük dosyalar için `bodySizeLimit` yine de 12 MB'a çıkarıldı (avatar, logo gibi).

## 3. İçerikler liste oldu ✅

Izgara yerine **satır listesi**. 100.000 kayıtta ızgara hem çok yer kaplıyor hem tarayıcıyı yoruyordu.

Performans önlemleri:
- Görsellerde `loading="lazy"` + `decoding="async"` — ekranda olmayanlar indirilmiyor
- Sabit satır yüksekliği (58px kapak) — düzen kaymıyor
- Sayfa başına 40 kayıt, sunucu tarafı sayfalama
- **Sıralama indeksleri** eklendi (`created_at desc`)
- **Trigram indeksleri** (`pg_trgm`) — `ilike '%...%'` aramaları indekssiz sürünüyordu

## 4. Video kapağı ✅

Kapak arama listesi genişletildi: `image_url` → `cover_url` → `thumbnail_url` → `poster_url` → `kapak` → `cover` → `photo_url` → `images[]` → `gorseller[]` → `media[]` …

**Hiç görsel bulunamazsa video adresinden ilk kare gösteriliyor** — `<video preload="metadata">` ile, `#t=0.5` parametresiyle yarım saniyedeki kare. Poster kolonu hiç olmasa bile kapak boş kalmıyor.

> Yine boş kalırsa SQL dosyasının sonundaki **tanı sorgusunu** çalıştır. Tablondaki medya kolonlarını listeliyor ve "✗ TANINMIYOR" işaretliyor. O kolon adını bana söyle, listeye eklerim.
